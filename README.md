# neural-network-math-simulator

## 🎯 Features

1. **Visual feedback:** Neurons glow when active
2. **Step-by-step math:** Every calculation shown with explanation
3. **Real-world examples:** Weather, fruits, games
4. **Emoji indicators:** Makes it more engaging
5. **Color coding:** Green (important), Red (irrelevant), with visual contrast
6. **Progressive disclosure:** Information revealed step-by-step, not all at once
7. **Ethical awareness:** Teaches responsible AI development
8. **Contrast learning:** Shows both good and bad inputs side-by-side
9. **Weight visualization:** Makes abstract concept concrete
10. **Live parameter counter:** Shows how many weights each network has (e.g., "12 total weights") with comparison to GPT-3 (175 billion)
